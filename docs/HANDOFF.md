## Environment facts that will bite you

1. **Lovable deploys from `main`.** `gagaskin.lovable.app` serves `main`, so anything on the
   feature branch 404s there. That is expected, not a bug. Merging to `main` is shipping.
2. **No agent applies SQL.** Mike pastes it into the Lovable UI by hand. Migration files in
   `supabase/migrations/` are a record of what he applied, never a mechanism. Never run
   `supabase db push` or any migration runner.
3. **Never force-push, rebase, amend or squash.** Lovable syncs from `main`.
4. **`git pull origin main` before every session.** ChatGPT, Antigravity and Lovable all
   write to this repo. An earlier unmanaged run left 43 uncommitted files, preserved on the
   branch `checkpoint/codex-validation-shell`.
5. **`src/routeTree.gen.ts` is generated.** Regenerate with a build; never hand-merge it.
6. **`src/integrations/supabase/types.ts` is generated by Lovable** and has NOT regenerated
   since the schema was applied. New tables therefore go through `src/lib/db.ts`. **Delete
   that file and import `supabase` directly once `types.ts` names the new tables** — the
   call signatures are deliberately identical.

## Gotchas already paid for — do not rediscover these

- **`npm run build` does not typecheck.** Vite builds happily over type errors. Always run
  `npx tsc --noEmit` separately.
- **Neither build nor tests catch runtime errors.** A detached `this` on `supabase.rpc`
  broke every public page while typecheck, 57 tests and the build all passed. **Load every
  route in a browser before calling it done.** Use the `preview_start` / `navigate` tools.
- **Never destructure Supabase client methods.** `const rpc = supabase.rpc` detaches the
  receiver and supabase-js fails on `this.rest`. Call them as methods on the client.
- **`exactOptionalPropertyTypes` is on.** An optional key must be *absent*, not set to
  `undefined`. See `validateSearch` in `src/routes/editor.tsx` for the pattern.
- **`validateSearch` makes `search` required** on every `navigate`/`Link` to that route
  unless the return type is annotated optional.
- **A typed `Link` to a route that does not exist yet fails typecheck.** Nav entries in
  `SiteShell` are added by the task that creates each route.
- **The preview pane reports `clientWidth: 0` until resized.** Call `resize_window` before
  measuring overflow, or the numbers are meaningless.

## Rules the copy must follow

`src/test/copy.test.ts` enforces these and fails the suite if broken. It is verified to
catch violations. If it fails, fix the copy, never the test.

- Never call the product an AI skin generator. `/build` must not mention AI at all.
- Never write "Genious". The offer is **Human Creator Custom Orders**.
- No turnaround promises, user counts, star ratings, testimonials, or likeness claims.
- Offer names are exact: **AI Helper**, **Human Creator Custom Orders**, **Awesome Editor**.
- Every gallery before/after pair carries the path that made it. An unlabelled pair implies
  an outcome-fidelity claim the product has not validated.
